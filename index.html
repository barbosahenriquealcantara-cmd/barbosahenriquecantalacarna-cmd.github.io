Podcast Clipper

O Podcast Clipper é um aplicativo desktop local que automatiza a criação de clipes curtos a partir de podcasts longos. Ele processa vídeos do YouTube, transcreve o conteúdo, identifica os momentos mais interessantes e gera clipes verticais otimizados para redes sociais.

Este aplicativo se integra à API do YouTube para realizar o upload dos clipes finalizados no canal do próprio usuário, permitindo também o agendamento nativo de publicações.
